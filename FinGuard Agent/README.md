# FinGuard Agent — 智能财报审查智能体

基于 Dify 工作流的自动化企业财务报表审查系统。上传财报文档即可自动提取关键财务数据，并由 CFO 角色 AI 进行深度风控诊断，生成结构化风险报告。

## 功能概述

FinGuard Agent 是一个面向企业财务风控场景的 AI 智能体。它将传统的人工财报审阅流程自动化，通过两级 LLM 协作完成"数据提取 → 风险诊断 → 报告生成"全链路：

| 阶段 | 节点 | 功能 |
|------|------|------|
| 输入 | 用户输入 | 上传 PDF/DOCX 格式财报文件 |
| 解析 | 文档提取器 | 提取文档中的文本内容 |
| 提取 | LLM 1 | 从文本中结构化提取核心财务指标 |
| 诊断 | LLM 2 | CFO 角色深度分析，生成风控报告 |
| 输出 | 输出 | 返回结构化 Markdown 报告 |

## 工作流程

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  用户输入     │────▶│  文档提取器    │────▶│  LLM 1       │────▶│  LLM 2       │────▶│  输出        │

│  (PDF/DOCX)  │     │              │     │  结构化提取    │     │  生成报告     │     │  (Markdown)  │
└──────────────┘     └──────────────┘     └──────────────┘     └──────────────┘     └──────────────┘
```

## 节点详解

### 1. 用户输入（Start）

接收用户上传的企业财报文件。

| 参数 | 说明 |
|------|------|
| 变量名 | `financial_pdf` |
| 类型 | 文件上传 |
| 允许类型 | document（PDF/DOCX 等） |
| 必填 | 是 |

### 2. 文档提取器（Document Extractor）

自动解析上传的文档，提取纯文本内容，传递给下游 LLM 节点。

### 3. LLM 1 — 财务数据结构化提取

专业的数据结构化提取专家，负责从财报文本中精准提取核心财务指标。

**提取原则**：

- **纯数字输出** — 去掉千分位逗号、货币符号、单位文字（如 "1,234.56万元" → "12345600.00"）
- **单位自动转换** — 万元 × 10,000、亿元 × 100,000,000，自动转换为元
- **符号识别** — 括号 "(123.45)" 识别为负数 "-123.45"
- **缺失处理** — 无法确认的数值设为 "0"
- **报表口径** — 仅提取合并财务报表数据，区分本期与上期

**提取的财务科目**：

| 科目 | 来源报表 |
|------|----------|
| 营业收入 | 利润表 |
| 净利润（归母） | 利润表 |
| 扣除非经常性损益后净利润 | 利润表 |
| 经营活动现金流量净额 | 现金流量表 |
| 资产总计 | 资产负债表 |
| 负债合计 | 资产负债表 |
| 应收账款期末账面价值 | 资产负债表 |
| 存货期末账面价值 | 资产负债表 |
| 短期借款 | 资产负债表 |
| 货币资金期末余额 | 资产负债表 |

### 4. LLM 2 — CFO 深度审查推理

以大型产业集团首席财务官（CFO）的角色进行诊断，拥有 20 年以上财务分析、信贷审批与反舞弊经验。

**诊断规则**：

1. **纯数字驱动** — 所有结论必须回溯到具体指标数据，禁止模糊说辞
2. **预警第一原则** — 触发硬性风险预警时，必须详细解释潜在商业危机
3. **交叉验证原则** — 盈利指标结合现金流、负债结构交叉检验
4. **前瞻性评估** — 评估未来 12 个月内可能爆发的流动性与合规风险

### 5. 输出（End）

返回结构化风控报告，变量名为 `result`。

## 安装与导入

### 环境要求

| 组件 | 说明 |
|------|------|
| Dify | 0.6.0+ |
| 火山引擎 API Key | 豆包模型调用 |

### 导入步骤

1. 登录 Dify 平台
2. 进入「工作室」→ 点击「导入 DSL 文件」
3. 选择 `公司财报审查.yml` 文件上传
4. 导入后进入工作流编辑器

## 配置

### 模型配置

导入后需重新配置两个 LLM 节点的模型提供商：

1. 点击 **LLM 1（数据提取）** 节点 → 选择你的火山引擎豆包模型
2. 点击 **LLM 2（CFO 审查）** 节点 → 选择同一模型

两个节点均使用以下配置：

| 参数 | 值 | 说明 |
|------|-----|------|
| Temperature | 0.7 | 输出随机性 |
| 模式 | Chat | 对话模式 |

### 模型依赖

工作流使用以下 Dify 插件：

- **火山引擎 MaaS** (`langgenius/volcengine_maas`) — 提供豆包系列模型调用能力

## 输出报告结构

LLM 2 输出的风控报告严格遵循以下 Markdown 结构：

```
### 🚨 数据风控综合判定
一句话定性：极度稳健 / 正常运转 / 存在特定滑坡隐患 / 财务高危

### 📊 指标层深度诊断
- 成长性与盈利质量评估
- 现金流造血能力分析
- 流动性与偿债防线安全度

### 🔍 核心风险因子拦截说明
- 风险因子 1：具体财务异常及连锁反应
- 风险因子 2：...
- 未触发但接近阈值的补充警示

### 📝 财务合规性补充调阅建议
- 定向调阅建议 1
- 定向调阅建议 2

### 📌 总结评价
整体评价与建议
```

## 适用场景

- **信贷审批** — 快速评估贷款企业的财务健康状况
- **供应链风控** — 审查上下游供应商/客户的财务风险
- **投资尽调** — 初步筛查标的公司的财务质量
- **内部审计** — 辅助审计团队识别财务报表异常信号
- **监管合规** — 批量审查企业财报合规性
